Propiedades matemáticas importantes

  1. Simetría: \( r_{xy} = r_{yx} \). El coeficiente es el mismo sin importar qué variable se considera X o Y.
  2. Invarianza ante cambios de escala y origen: Si transformamos \( x' = a + bx \) (\( b>0 \)) y \( y' = c + dy \) (\( d>0 \)), entonces \( r_{x'y'} = r_{xy} \).
  3. Rango acotado: Siempre se cumple \( -1 \leq r \leq 1 \).
  4. Relación con la regresión lineal: El coeficiente de determinación \( R^2 \) de una regresión lineal simple es igual a \( r^2 \). Indica la proporción de variabilidad de Y explicada linealmente por X.
  5. Sensibilidad a la covarianza: \( r \) es proporcional a la covarianza estandarizada.

Limitaciones importantes

1. Solo detecta relaciones lineales

Si la relación es curva (forma de U, J o S), Pearson puede dar un valor cercano a cero aunque exista una relación fuerte. Siempre graficar.

2. Muy sensible a valores atípicos (outliers)

Un solo punto extremo puede aumentar o disminuir drásticamente el valor de \( r \). Considerar Spearman o Kendall cuando haya outliers.

3. No implica causalidad

Una correlación alta no significa que una variable cause a la otra.

Otras limitaciones

  • Restricción de rango: Si se limita artificialmente el rango de una variable, \( r \) tiende a disminuir.
  • No adecuado para variables categóricas: Usar chi-cuadrada, Spearman, Kendall, V de Cramer, etc.
  • Dependencia del tamaño muestral para la significación: Muestras grandes hacen significativas correlaciones pequeñas.

¿Cuándo NO usar Pearson?

SituaciónAlternativa recomendada
Relación no linealSpearman, modelos no lineales
Presencia de outliers importantesSpearman o Kendall
Variables ordinalesSpearman o Kendall
Variables categóricasChi-cuadrada + V de Cramer
Muestras muy pequeñasKendall (más robusto)
Datos con muchos empatesKendall

Conclusión: Pearson es excelente cuando se cumplen sus supuestos (relación lineal, pocos outliers, variables cuantitativas). El analista responsable siempre debe visualizar, verificar supuestos, considerar alternativas y interpretar con cautela.
